# dotfiles

macOS developer bootstrap using chezmoi, Homebrew Bundle, and a single install script.

## New Laptop Setup

1. Install Xcode Command Line Tools:

```sh
xcode-select --install
```

2. Clone and install:

```sh
git clone git@github.com:flohop/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

This will:
- Install Homebrew (if missing)
- Install chezmoi (if missing)
- Apply all dotfiles via chezmoi (`~/.zshrc`, `~/.tmux.conf`, `~/.config/`, `~/bin/`, etc.)
- Install all CLI tools and apps from `Brewfile`
- Apply macOS defaults

3. Restart your terminal.

## cmux

[cmux](https://cmux.com) reads two files, and both are tracked here.

| File | What it sets |
| --- | --- |
| `~/.config/cmux/cmux.json` | Ctrl+A shortcuts, sidebar, notifications, Claude Code integration, agent session auto-resume |
| `~/.config/ghostty/config` | Font, theme, colors, scrollback, Cmd+C passthrough. cmux uses this for its terminals, and so does standalone Ghostty. |

### Set up cmux on a Mac that already has it

Use this when cmux is installed and you only want its setup, not every dotfile.

1. Get the repo, or update it if it is already cloned:

```sh
git clone git@github.com:flohop/dotfiles.git ~/dotfiles
# already cloned: cd ~/dotfiles && git pull
```

2. Install chezmoi and the font the Ghostty config uses:

```sh
brew install chezmoi
brew install --cask font-jetbrains-mono-nerd-font
```

3. Back up whatever is there now:

```sh
cp ~/.config/cmux/cmux.json ~/.config/cmux/cmux.json.bak 2>/dev/null
cp ~/.config/ghostty/config ~/.config/ghostty/config.bak 2>/dev/null
```

4. Preview, then apply only the two cmux files:

```sh
chezmoi diff  --source="$HOME/dotfiles" ~/.config/cmux/cmux.json ~/.config/ghostty/config
chezmoi apply --source="$HOME/dotfiles" ~/.config/cmux/cmux.json ~/.config/ghostty/config
```

5. Optional: choose the folder new workspaces open in. Without this they open in your home folder.

```sh
echo "working-directory = $HOME/code" > ~/.config/ghostty/local
```

`~/.config/ghostty/local` is per machine and not tracked. The shared config loads it last, so it can override anything else too.

6. Reload and check:

```sh
cmux reload-config
cmux config check
```

7. Agent integrations:
   - Claude Code needs nothing more. `cmux.json` turns it on. Restart any `claude` session that was already running.
   - Codex: run `cmux hooks codex install`. It writes hooks with paths for this machine, which is why they are not tracked.

### Shortcuts

Press Ctrl+A, let go, then press the second key.

| Keys | Action |
| --- | --- |
| Ctrl+A, c | New workspace |
| Ctrl+A, \| (Shift+\\) | Split right |
| Ctrl+A, - | Split down |
| Ctrl+A, h / j / k / l | Focus pane left / down / up / right |
| Ctrl+A, o | Next pane |
| Ctrl+A, z | Zoom pane |
| Ctrl+A, , | Rename workspace |
| Ctrl+A, n / p | Next / previous workspace |
| Ctrl+A, w | Workspace switcher |
| Ctrl+A, [ | Copy mode |
| Ctrl+A, u | Open the cmux browser |
| Ctrl+A, i | Notifications |
| Ctrl+A, r | Reload cmux and Ghostty config |
| Cmd+1–9 | Go to workspace |
| Cmd+Option+Up / Down | Move workspace up / down |
| Cmd+Option+1–9 | Go to a terminal tab in the current pane |
| Cmd+Shift+U | Jump to the latest unread notification |

Hold Cmd for about half a second to see the workspace numbers.

### Not tracked

- `~/Library/Application Support/cmux/` holds sessions, history and the search index for one machine.
- The `com.cmuxterm.app` preferences hold window positions and account IDs. Every setting worth keeping is in `cmux.json`.
- `~/.codex/hooks.json` and `~/.cmux/hooks/` are generated by `cmux hooks`.

To change the setup later, edit the live file, run `cmux reload-config`, then sync it back as described under "Editing a tracked dotfile".

## Day-to-Day Usage

### Adding a new dotfile

```sh
chezmoi add ~/.some-config
cd ~/dotfiles && git add -A && git commit -m "Add some-config" && git push
```

### Editing a tracked dotfile

Edit the real file, then sync back:

```sh
chezmoi re-add ~/.zshrc
cd ~/dotfiles && git add -A && git commit -m "Update zshrc" && git push
```

### Pulling changes on another machine

```sh
cd ~/dotfiles
git pull
chezmoi apply --source="$HOME/dotfiles"
```

Or re-run `./install.sh` to also update Homebrew packages.

### Adding a new brew package

```sh
brew install <package>
# Add it to Brewfile, then commit
```

## Secrets Warning

Do not commit SSH keys, tokens, `.env` files, API keys, or credentials. Keep those in a password manager.
